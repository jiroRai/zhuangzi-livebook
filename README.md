# 庄子 · 互动书

一本放在橡木书桌上的《庄子》立体书：用 Three.js 建模，翻开封面，每篇先读原文，再接白话译文——三十三篇逐页可读，保留文言原文与白话两套文字。每一篇开头有一页导读，对页是一幅墨线插图——翻到那里，纸片会先像印刷一样浮现在纸面，再一张张立起来动起来。

在线阅读：<https://cocohahaha.github.io/zhuangzi-book/>

![桌上的书](screenshots/desktop-open.png)

## 怎么读

- **翻页**：滚动鼠标滚轮或触控板（一次滑动只翻一页）、按 ← → ↑ ↓ / 空格 / PageUp PageDown，或点书的左右两半；也可以拖动书页，页角会跟着手卷起来。
- **手机**：竖屏时一次看一页，左右或上下滑动、轻点屏幕左右两侧，就在左右页之间移动、翻页。
- **插图**：翻到插图页，纸片自己立起来、故事自己演，不用点。图里的人和物会依次亮起、做个小动作，图下用手写体写出一两句白话说明，「图中」里的小圆圈依次被朱笔点上。用鼠标时也可以点图里的东西，提前看到那一条。
- **原文页**：每篇插图之后、白话之前，新增按节分页的原文页（楷体），节标题用标题字体；原文页末尾提示「白话译文见后」。
- **页边旁批**：正文里有名的故事（庖丁解牛、濠梁之辩、白驹过隙……），翻到时页边会用朱笔写出名目，正文下划一道。
- **精读记号**：原文与白话里的概念、人物、地名、关键词会以底色/下划线/粗体标出，翻到页面时逐笔浮现；点记号弹出纸笺词卡（释义、出处，有人物的带小像）。**古今异义只在原文标注，白话正文不标**，避免把现代词义误当古义。导读前新增「记号说明」页。
- **导读页的「本篇故事」**：点标签直接翻到那一页。
- **目录**：左上角菜单按钮打开左侧边栏，按内篇/外篇/杂篇分组，直接点篇名跳转；也可以在目录页点篇名。
- 会记住读到哪里，下次打开接着读；也可以用 `#p=页码` 直接打开某一页（就是书页上印的页码），例如 `#p=34`（养生主）。
- **声音**：右上角按钮开关翻页声（声音由 WebAudio 现场合成）。

## 内容

- 白话：`content/zhuangzi.json`，三十三篇逐篇改写的现代白话，约十三万字，底本维基文库《莊子》（公有领域）。
- 原文：`content/original.json`，33 篇、约 8 万字，按节分页；由 EPUB 构建产物重建（生僻字保留，缺字用回退字体补齐）。
- 记号：`content/marks.json`，393 条（概念 141、人物 120、关键词 60、地名 44、古今异义 28），带分类/释义/小像。
- `scripts/build_assets.py` 生成上述两份 JSON 与 `fonts/*.woff2`、`fonts/fonts.css`，并从 EPUB 工程复制字体许可到 `fonts/licenses/`。
- 白话导读、插图批注、页边旁批写在 `js/copy.js`；`node scripts/check-copy.mjs` 核对旁批关键词都在正文里，并检查有没有文言残留和生僻字。

## 技术

纯静态页面，运行时不需要构建；Three.js（r170）放在 `vendor/` 里，不依赖 CDN。改原文/记号/字体后运行 `python scripts/build_assets.py` 重新生成 `content/*.json` 与 `fonts/*.woff2`（脚本会读 EPUB 工程产物，一次性生成）。

```
index.html          页面与底栏
css/app.css         界面样式
js/app.js           主程序：状态、翻页、拖拽、镜头、阅读位置
js/book.js          书的模型：精装封面、书脊、书块、会卷曲的书页（curl / bulge / droop）
js/stage.js         橡木桌、皮革书写垫、灯光（天光 / 主光投影 / 侧补光）、竹影
js/pages.js         方格排版（避头尾、句末标点悬挂）与每页的 canvas 绘制
js/popup.js         立体插图框架：纸片折起、翅膀、墨线、可点的热区
js/ink.js, art.js   毛笔线、淡彩、人物、树、山、水、云等墨线造型
js/scenes/          各篇插图
js/audio.js         翻页、纸片、落笔的合成音效（本次已降高频/音量）
vendor/three/       three.module.min.js 与 Line2 线条扩展
content/zhuangzi.json  白话正文
content/original.json  原文（按篇/节）
content/marks.json     精读记号词表
fonts/                  网页字体子集与许可
```

本地预览需要通过 HTTP 打开（直接双击 `index.html` 读不到 JSON 和模块）：

```sh
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 字体与许可

| 用途 | 字体 | 许可 |
|---|---|---|
| 原文正文 | 方正手迹·欧蝶正楷（简） | 方正个人使用，勿公开部署 |
| 原文缺字回退 | 霞鹜文楷 / 思源宋体（Ext-B、PUA） | OFL / 系统字体 |
| 白话正文 | 狮尾加糖宋体 Swei Sugar Medium / Bold | OFL-1.1 |
| 标题/人名/小节序号 | CooperZhengKai 1.4 | OFL-1.1 |
| 批注/插图手写 | Ma Shan Zheng | OFL-1.1 |

字体文件在 `fonts/`，许可文本在 `fonts/licenses/`。**方正字体与 SimSun 回退只适合个人阅读，不要公开部署这版网站。** 若要公开，把 `js/ink.js` 的 `FONTS.kai` 换回 OFL 楷体、并删掉 `fonts/kai-*` 中的方正/SimSun 子集后重新生成即可。

## 本次加强版改动

- 保留原有全部 Three.js 动画与插图交互，修复翻页动画中书页不可见的复用 bug；
- 每篇新增原文页（楷体、按节分页、可读性调优）；
- 移植 EPUB 精读记号：五类语义底色 + 下划线 + 粗体，翻页时逐笔出现，点词弹卡；白话正文不标古今异义；
- 原文/白话/标题分别使用 EPUB 字体；批注橙色手写效果保留；
- 目录收进左上角可展开边栏，声音按钮移到右上角；
- 记号词卡改为纸笺样式（纸纹、胶带、红章）；
- 翻页声降低高频与音量，改为更柔和的纸张摩擦声；
- 新增「记号说明」页与字号更清楚的图例。
